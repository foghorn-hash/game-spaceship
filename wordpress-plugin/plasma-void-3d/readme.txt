Nopeatempoinen 3D-avaruusräiskintäpeli WordPress-sivustoille.

== Description ==

Plasma Void 3D tuo sivustollesi modernin WebGL/Three.js -pohjaisen 3D-avaruuspelin. Pelaaja ohjaa neon-alustaan, ampuu kiihdytettyjä plasmapuikkoja ja taistelee kehittyviä 3D-avaruussotalaivoja vastaan.

= Ominaisuudet =
* Helppo lyhytkoodi: `[plasma_void_3d]`
* Mukautettava leveys ja korkeus
* Koko näyttö (Fullscreen) -tuki yhdellä napilla
* Äänet ja synthwave-taustamusiikki Web Audio APIlla
* Mobiili- ja kosketusnäyttötuettu
* Yhteensopiva Gutenbergin, Elementorin ja Classic Editorin kanssa

== Installation ==

1. Lataa `plasma-void-3d.zip` WordPressin hallintaan (Lisäosat -> Lisää uusi -> Lataa lisäosa).
2. Ota lisäosa käyttöön.
3. Lisää lyhytkoodi `[plasma_void_3d]` mille tahansa sivulle tai artikkeliin.

== Frequently Asked Questions ==

= Miten muutan pelin kokoa? =
Käytä parametreja:
`[plasma_void_3d width="100%" height="700px"]`

= Toimiiko mobiililaitteilla? =
Kyllä, pelissä on automaattiset virtuaaliset kosketusohjaimet älypuhelimille ja tableteille.
